Histórico local de rotas

Salve cada rota neste navegador. O histórico fica neste dispositivo/perfil e não é enviado a servidor algum. Exporte um backup JSON para não depender apenas do armazenamento do navegador.

Como usar os indicadores

  • “Pacotes atribuídos” é o volume recebido para a rota; “entregues” e “insucessos” registram o resultado final. O sistema não presume que a soma desses campos sempre será igual ao total, pois pode haver novas tentativas, devoluções e divergências de registro.
  • “Paradas previstas” conta destinos planejados. “Paradas realizadas” registra os destinos atendidos/tentados conforme o critério adotado; mantenha o mesmo critério para comparar rotas.
  • O custo por pacote atribuído usa todos os pacotes informados; o resultado por pacote entregue divide o saldo pelos entregues com sucesso. A taxa de entrega não é limitada artificialmente: divergências acima de 100% são sinalizadas para conferência.
  • O resultado é uma estimativa operacional, não lucro contábil ou cálculo de obrigações tributárias. Só são considerados os custos que você preencher.
