# NÚCLEO 89 — Calculadora Operacional de Rotas

**Desenvolvido por NÚCLEO 89**

Calculadora operacional independente para entregadores e profissionais de logística que desejam analisar os custos, a produtividade e a rentabilidade de suas rotas.

### Objetivos
- Estimar os custos de combustível e operação do veículo.
- Considerar manutenção, pneus, depreciação e despesas de trabalho.
- Acompanhar entregas, insucessos, devoluções e produtividade.
- Gerar relatórios operacionais para consulta e análise.
- Incentivar decisões mais conscientes sobre a rentabilidade das rotas.

### Características
- Aplicação HTML, CSS e JavaScript.
- Funcionamento local no navegador.
- Sem necessidade de servidor para os cálculos.
- Projeto de código aberto sob licença MIT.

### Aviso
Os resultados são estimativas baseadas nos dados informados pelo usuário. A ferramenta não substitui controles contábeis, fiscais ou financeiros profissionais.
